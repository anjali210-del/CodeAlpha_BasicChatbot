# CodeAlpha Task 4 – Basic Chatbot

## Project Description
A simple rule-based chatbot developed using Python. It interacts with users through predefined responses based on their messages.

## Features
- Responds to greetings such as hello and hi.
- Answers simple questions.
- Provides predefined replies.
- Uses a continuous conversation loop.
- Ends the conversation when the user says goodbye.

## Technologies Used
- Python
- Functions
- If-elif-else statements
- While loops
- User input and output
- String handling

## How to Run
1. Install Python.
2. Open the project folder in VS Code or Command Prompt.
3. Run:

`python chatbot.py`
